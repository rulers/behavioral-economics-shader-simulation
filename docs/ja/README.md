## プロジェクトの目的

TypeScript、WebGL2、GLSLを使い、行動経済学のモデルをエージェントの意思決定ルールへ変換し、GPU上でシミュレーションします。

最初から大規模な汎用シミュレーション基盤を作るのではなく、Conway's Game of Life（ライフゲーム）を基準モデルとして、行動モデルを一つずつ追加し、その影響を再現可能な形で比較します。

## 実装順序

1. Conway baseline（ライフゲーム基準実装）
2. GPU Ping-Pong Textureによる状態更新
3. Prospect Theory / Loss Aversion（プロスペクト理論 / 損失回避）
4. Herding / Conformity（群集行動 / 同調）
5. 必要性が確認できた段階で共通インターフェースを抽出

## ローカル環境と動作確認

簡易ライフゲームは静的なHTML/CSS/JavaScriptアプリです。npmパッケージやビルド工程は不要で、ローカルWebサーバー用にPython 3を使います。

Python 3が利用できることを確認します。

```sh
python3 --version
```

リポジトリのルートでサーバーを起動します。

```sh
sh simulator/lifegame-simple/run-local.sh
```

ブラウザーで <http://127.0.0.1:8000/> を開くとシミュレーター一覧が表示されます。一覧からライフゲームを開いてください。別のポートを使う場合は、たとえば次のように起動します。

```sh
PORT=8080 sh simulator/lifegame-simple/run-local.sh
```

別ポートの場合は <http://127.0.0.1:8080/> を開きます。終了するにはターミナルで `Ctrl+C` を押します。一覧からアプリを開き、盤面へのセル配置、1世代進行、再生と一時停止、速度変更、ランダム生成、クリアを操作して確認してください。この単体アプリ用の自動テストランナーはまだありません。
